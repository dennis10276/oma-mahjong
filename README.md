# Oma's Mahjong

Rustig Mahjong puzzelen zonder reclame — een Android-app in het Nederlands.

**Download:** https://dennis10276.github.io/oma-mahjong/

- `index.html` + `OmasMahjong.apk`: de downloadpagina
- `play/`: het spel zelf (ook speelbaar in de browser)
- `source/android/`: de Android-wrapper en het bouwscript
