## Later use: is a level humanly possible?

- **Witnessed human-legal clear:** a replayable production winning trace with
  decisions justified by available information. State actual attempts, aids,
  timing, clock costs, observation and memory assumptions. This proves a route
  on the deal, not that every human can find or execute it.
- **Unresolved:** no clear found within declared computation, observation or
  execution limits. Never relabel this as impossible.
- **Proven impossible under stated assumptions:** requires an independently
  checked exhaustive proof for the specified state and production rules.
  Low empirical success or bounded search failure is insufficient.
- **Practical human difficulty:** requires separate evidence about recognition,
  planning time, memory, execution and human success probabilities. Public
  information alone does not imply human-speed search or guaranteed success.

Do not use the current reference score as a personal prediction accuracy
certificate or as a universal human-possibility decision procedure.
