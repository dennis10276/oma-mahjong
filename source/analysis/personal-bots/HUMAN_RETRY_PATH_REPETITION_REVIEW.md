# Are the remaining losses identical retries?

Compared complete recorded tap sequences within each board/salt of adopted08's
eight open Track A boards. This uses the already independently replayed full08
records, not new games, search or hidden-role labels. No complete tap sequence
repeats within any of the24 campaigns:200 attempts,189 physical losses,11 clears.

This contradicts a simple identical-route-loop explanation for these failures.
It does not exclude the same physical position reached through different move
orders, repeated bad local choices, or choices made without useful new knowledge.
Those require a public-state-and-semantic-memory audit. A path hash alone cannot
justify claiming the bot is or is not repeating the same underlying mistake.
