## Reasoning and implementation

Existing loss memory records an actual observed root only after the public
search exhausts every legal root, with no reachable unknown, unsupported
transition or budget boundary. It does not generalize its open-peek identity.
A known, non-losing inspection reachable from that exhausted losing root must
also lose: a winning continuation there would contradict the parent's proof.

rememberLossInspections:true requires rememberKnownLosses:true. From a genuine
actual exhausted root, run the existing known-only advance for each available
root. Store only zero-removal inspections that change the open peek while
preserving alive tiles, tray, moves, relief and arrivals. Unknowns, losses,
removals and other state changes are excluded. No picture or role is imagined.
No predecessor is condemned merely because one path reaches a losing state.

Derived entries retain the actual parent's signature and physical-tap witness,
the inspected index, proof kind and observedSuccessor:false. They are proved
planning facts, not invented observations. A bounded search or an ordinary
physical loss cannot supply the required exhausted public certificate. Existing
clock, arrival and relief distinctions remain in the loss key. Default behavior
is unchanged when the option is absent.
