replayed taps and four tray losses. No attempt tapped the clock. Its location, picture
and orientation were public, and hypothetical routes ended at an unknown clock role.
This did not establish current mechanical availability. The direct candidate trace

The opt-in `probeUnknownClock` rule probes an active clock already offered by the
public frontier when `advance` stops at unknown information. Default tray limit1
leaves two slots after a possible unmatched take. A free closed peek or known tray
match is also eligible. It preserves an existing known winning route and retained
two-tap information option. The default behavior is unchanged without this option.

This changes the primary policy, not the sampler's paired2SE override rule. Fast
honest play-outs inherit the same option. Only actual observation/rejection updates
memory. A rejected probe identifies ice-or-lock, not its concealed type. Existing
public blocked-tap memory prevents an unchanged rejected clock from being retried.
No successful clock exit or complete win is assumed from a probe.
