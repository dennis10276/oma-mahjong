# What changes across retries?

Reference diagnostic samples only, not new ratings. Known route/pictures are measured after the opening observation and include currently visible faces as well as retry memory. Board medians prevent long failing campaigns from dominating familiarity. Later bins contain only campaigns that have not already won; denominators/boards differ. These are descriptive survivor-selected comparisons, not causal memory gains. Remembered key identity and known pictures remain separate.
