# Speed controls and limits

The speed section of Task10 was noticed after the main grid finished. The original grid and paired knob/trap comparisons all received the frozen full protocol. Actual savings there are zero. `speed-range-replay.json` is explicitly retrospective, not a claim of saved computation.

The standalone wrapper leaves the frozen bot, profiles, physics, attempt cap and full-rating settings unchanged. Screening uses two exact successive blocks of10 campaigns from seed4711's original stream. The second block shifts its seed by `imul(10, 0x9e3779b9)`, so it continues campaigns11–20. No board stops after only10. Survivors run the unchanged full calls; the repeated prefix is counted as overhead. Shortened checks remain unqualified and have no full family/skilled score.

Calibration read existing Task09-pool and clock-spare measurements, without launching bots. It deduplicated physical boards and compared their retained first20 outcomes against their full scores. Family margin4 falsely stopped12/696 potentially qualifying boards, 1.724%, below the requested2%. The family test checks every curve target for which a full score could qualify. This is empirical calibration, not a statistical guarantee. Full evidence and other tested margins are in `speed-calibration.json`.

The skilled wrapper checks both route and plain styles independently. Both prefixes must lie on the same side of2.5–6 by more than margin1 before rejection. It never chooses a different winning style per block. Old cached API records retain only the full winning style's individual outcomes: rejection of that style's prefix is a necessary condition for this both-styles rule. That conservative upper-bound calibration falsely rejected0/119 full in-band skilled boards. No exact two-style retrospective savings are invented.

Prediction uses plain additive fits on training cells only, with separate predictions from the requested brief and actual card. Both must agree more than3 tries outside the same profile's band before a skip. Unknown predictions and unsupported spare values do not skip. A fixed hash selects20% of predicted skips for full family/planner auditing, bypassing early stopping. The requested-feature fit gives each repeated cell one mean; the card fit uses actual returned descriptors. These models are associations among buildable boards.

Retrospective range check:87/192 fully rated grid boards would be prediction skips. Its15 hash-selected audits contain zero missed joint-band boards; checking all87 also finds zero. On held-out grid boards specifically,21/54 would skip, with zero missed joint-band boards. There is only one joint-band board in the entire study: this is weak evidence about recall, not a validated universal filter. Family prefix replay at range-band centre11.5 would stop175/192, missing none of that single joint-band example.

Pilot:11 successful constructions; zero prediction skips, hence no prospective prediction-skip audits. Existing static/quality rejections, counterfactuals, fresh checks and cache verification are kept separate; no fresh check was needed because no new candidate qualified.
