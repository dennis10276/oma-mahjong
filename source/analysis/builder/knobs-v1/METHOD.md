# Task 10 method

This folder starts with immutable inputs, not a finished result. The live run is
in `source/build/builder-knobs-v1`; see `source/build/TASK-10-RUNNING.md`.

The fixed preparation produced 24 base puzzles, 168 variant requests and 282
range requests. There are 339 proven boards and 135 explicit failures. Each
successful board receives two family measurements (4711 and18427, forty seeded
campaigns each) and the standard frozen planner measurement (4711; the better of
route/plain styles, each forty campaigns). This is 1,017 logical measurements,
before the later trap, diagnostic and pilot addenda. The retry yardstick caps at20.

Same-puzzle variants retain geometry, clock tile, keys, locks, ice, planned dig
and holders. Baselines are rebuilt through the same `opts.keep` path as variants.
A rebuild that would shorten the dig or discard a special/holder fails before
any bot call. Spare is an exact clock-only transform. Its base intent text and
forced-pressure annotation are historical; the new timer and unchanged complete
witness are proved separately. Tolerance of one can leave a requested luck
increase with no actual increase; actual dose and non-target drift are reported.

The plain additive tables use story intercepts plus way, three-waiting, luck and
trap steps. Repeated seeds contribute one cell mean. Held-out cells are fixed
before ratings; a trap variant shares its zero-trap parent's fold. Unidentified
coefficients or predictions stay null. Report held-out median absolute errors,
not only training errors. The tables describe returned boards, not impossible
requests or human difficulty beyond the capped bot yardstick.

The later trap addendum selects one promising measured range cell per story,
then freezes its exact trap1 brief before any new measurements. Frozen-key
diagnostics select the lowest/highest pooled-family boards, with an id tie break.
Removing ice/locks is tested both with the original clock and with the same exact
spare, so a more generous timer does not masquerade as a pure role effect.

The v2 name `frozenGuards` means frozen keys plus a locked clock. The older lab
recipe of the same name freezes covers above the clock instead. These are
different mechanisms. The game and observer mask a frozen key's role as ice;
the planner follows visible key roles. The ablations test a source-based
hidden-role/routing hypothesis without changing the frozen bots.

If either study returns an observed point in family10–13 and skilled2.5–6, the
pilot fixes up to five original whole-layout requests per missing slot. All20
existing boards remain pinned, including their gold. The primary first-check
hit rate uses the initial pooled80-campaign family rating, before retuning or
the fresh29717 seed. Its denominator includes every successful builder output,
including later static or quality rejections. The4711-only rate is also reported.
New qualifiers must pass the existing Task09 quality/originality/window checks,
fresh29717 within±1, total seed spread≤2, and phone previews. No release is made.
